# SGOD — Scene-Graph Oracle Decoding

Training-free hallucination mitigation for Vision-Language Models. Augments LLM decoding logits with scores from an external scene graph oracle (RelTR + CLIP). Single forward pass; no self-referential verification.

See [docs/sgod_proposal.md](docs/sgod_proposal.md) for the full architecture proposal.

## Component 1 — SGG Module

Wraps RelTR to extract a scene graph (objects + relations + attributes) from an image once before generation. See `sgod/sgg/`.

### Unit tests (no GPU, no checkpoint)

```bash
pytest tests/test_sgg.py
```

Covers: `SceneGraph` data structure, `from_reltr_output()` factory, oracle activation threshold, text representations, image preprocessing, postprocessing, and class label constants.

Output: `outputs/test/last_run.xml` (JUnit XML, overwritten each run).

### Integration tests (requires checkpoint)

```bash
pytest tests/test_sgg.py -m integration
```

Runs end-to-end extraction with the real RelTR checkpoint. Tests: determinism, batch extraction, latency benchmark, model metadata.

Expected latency: ~50ms on GPU (T4), ~1000ms on CPU.

### Eval script — inspect output on an image

```bash
python scripts/eval_sgg.py \
    --checkpoint data/checkpoints/reltr/checkpoint0149.pth \
    --image path/to/image.jpg
```

Output is written to `outputs/eval/<timestamp>_sgg/results.json` automatically.

**Full options:**

| Flag | Default | Description |
|------|---------|-------------|
| `--checkpoint` | required | Path to RelTR `.pth` checkpoint |
| `--image` | — | Single image path |
| `--image_dir` | — | Directory of images (jpg/png/webp) |
| `--device` | auto | `cpu`, `cuda`, `cuda:0` |
| `--confidence` | `0.3` | Min confidence per triplet component |
| `--top_k` | `20` | Max triplets returned per image |
| `--benchmark` | off | Run latency benchmark after extraction |
| `--n_runs` | `100` | Number of benchmark iterations |
| `--output_json` | auto | Override output JSON path |

**Example with benchmark:**

```bash
python scripts/eval_sgg.py \
    --checkpoint data/checkpoints/reltr/checkpoint0149.pth \
    --image path/to/image.jpg \
    --benchmark \
    --n_runs 50
```

### Programmatic usage

```python
from PIL import Image
from sgod.sgg import SGGModule

sgg = SGGModule("data/checkpoints/reltr/checkpoint0149.pth")
image = Image.open("path/to/image.jpg")

sg = sgg.extract(image)

print(sg.to_text())           # human-readable
print(sg.to_prompt_prefix())  # compact string for VLM prompt injection
print(sg.summary())           # stats dict
print(sg.should_activate_oracle())  # False if avg confidence < 0.4
```

## Component 2 — Visual Oracle

Dual-source oracle that scores token candidates using structured scene graph confidence (SGG) + CLIP soft similarity as fallback. Built once before generation; used per anchor step. See `sgod/oracle/`.

**Scoring formula per anchor type:**

| Anchor type | Token in scene graph | Token NOT in scene graph |
|-------------|---------------------|--------------------------|
| `noun_anchor` | `w_sg × sg_conf + w_clip × clip_score` | `w_sg × (−0.3) + w_clip × (clip_score − 0.5)` |
| `relation_anchor` | `sg_conf` | `−0.2` |
| `attr_anchor` | `sg_conf` | `clip_score − 0.5` |

where `w_sg = sg_conf`, `w_clip = 1 − sg_conf`. All scores are in `[−1, 1]`.

### Unit tests (no GPU, no CLIP model)

```bash
pytest tests/test_oracle.py
```

Covers: `_build_conf_map`, vocabulary sets, noun/relation/attribute scoring formulas, batch_score shape and values, score range `[−1, 1]`, empty scene graph, duplicate objects, whitespace stripping.

Outputs:
- `outputs/test/last_run.xml` — JUnit XML (CI)
- `outputs/test/last_run.json` — human-readable JSON summary

### Pre-compute CLIP vocab embeddings (one-time, optional)

Without a vocab cache, `CLIPScorer` encodes each word live (~20ms each). Pre-computing reduces per-anchor scoring to ~1ms matrix multiply.

```bash
# Fast: RelTR classes only (~200 words)
python scripts/precompute_clip_vocab.py \
    --reltr_only \
    --output data/checkpoints/clip/clip_vocab_cache_reltr.pt

# Full: entire LLaVA vocabulary (~32K tokens)
python scripts/precompute_clip_vocab.py \
    --vlm_tokenizer llava-hf/llava-1.5-7b-hf \
    --clip_model ViT-L-14 \
    --output data/checkpoints/clip/clip_vocab_cache.pt
```

### Programmatic usage

```python
from PIL import Image
from sgod.sgg import SGGModule
from sgod.oracle import CLIPScorer, VisualOracle

sgg = SGGModule("data/checkpoints/reltr/checkpoint0149.pth")
image = Image.open("path/to/image.jpg")

sg = sgg.extract(image)

clip = CLIPScorer(
    image,
    vocab_cache_path="data/checkpoints/clip/clip_vocab_cache_reltr.pt",  # optional
)
oracle = VisualOracle(sg, clip)

# Score individual tokens
print(oracle.score("dog",   "noun_anchor"))      # >0 if dog is in scene
print(oracle.score("on",    "relation_anchor"))  # >0 if "on" is a detected relation
print(oracle.score("black", "attr_anchor"))      # >0 if "black" is a detected attribute

# Score a batch (used in decoding loop)
import torch
candidates = ["dog", "cat", "table", "sky"]
scores = oracle.batch_score(candidates, "noun_anchor")  # torch.Tensor[4]
```
